# Earlier versions (archived)

These folders hold earlier generations of the Small Files Archiving Solution.
They are kept for reference only and are no longer maintained. Use the current
version in the repository root ([`archiver/`](../archiver) and [`gui/`](../gui)).

| Folder | What it was |
|---|---|
| `v1/` | first version: tar bundling with CSV manifests, queried with Athena |
| `v2/` | Streamlit web UI on top of v1 |
| `sandbox/`, `scripts/` | experiments and test-data generators |
| `images/` | screenshots used by the v1/v2 READMEs |
| `Spec_for_small_file_archiving_solution.md`, `todo.md` | the original 2024 spec and to-do list |
